# Security reports

Please report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/sportwhiz/open-whiteboard/security/advisories/new). Do not post working credentials, private board content, or exploit details in a public issue.

Include the affected version, hosting adapter, steps to reproduce, and the impact you observed. Use a disposable installation where possible. We will review the report and coordinate a fix and disclosure with you.

The first public release has no long-term support branch. Use the latest reviewed release and read its upgrade notes. The presence of automated tests is not a guarantee that every vulnerability has been found.

Operators should keep registration restricted until recovery and backups have been tested, protect their hosting account, and monitor costs. See [Administration and recovery](docs/security-operations.md) for key storage, incident handling, and backups.
