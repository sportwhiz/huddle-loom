# Contributing

Thanks for taking time to improve Open Whiteboard. Bug reports, documentation fixes, accessibility improvements, and code changes are welcome.

Before building a large feature, open an issue describing the problem and how people would use the change. This helps us settle the scope before you spend time on it.

For a pull request:

1. Follow [Development](docs/development.md) to run the app.
2. Keep the change focused and add a regression test when it protects meaningful behavior.
3. Check the browser, Worker, and Node adapter affected by the change. Include screenshots for visible interface changes, in light and dark mode.
4. Explain the resulting behavior and the checks you ran. Mention any hosting or data-migration limits.

Do not include secrets, real customer data, private installation settings, or generated machine paths. Keep dependency notices current. Contributions to the project's own code are made under its MIT license; third-party files retain their existing terms.

Use issues for ordinary bugs. For a security vulnerability, follow [SECURITY.md](SECURITY.md).
